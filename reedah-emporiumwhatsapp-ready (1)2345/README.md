# Reedah's Emporium — ready-to-upload Vercel site

This folder is prepared for the `babybrownish/reedah_emporium` GitHub repository.

## What was added

- Two supplied Reedah's lip-gloss photos.
- A dedicated **Reedah's Emporium — Lip Gloss Shades** product section.
- Shade selector: Clear, Nude, Brown, Pink, Berry.
- Selecting a shade changes the displayed product photo.
- The selected shade is saved in the shopping bag.
- The selected shade is included in the WhatsApp order message.
- Responsive mobile layout.

## Upload

Upload/replace these files in the repository:

- `index.html`
- `style.css`
- `script.js`
- everything inside `images/`

Commit to the `main` branch.

Because the Vercel project is already connected to the repository, Vercel should automatically create a new deployment after the GitHub commit.

## Note about the shade photos

The five shade thumbnails are crops from the supplied product photo. They are visual representatives of the colors visible in the photo. If you later send individual photos for each exact shade, those files can replace the five crop images without changing the selector code.
